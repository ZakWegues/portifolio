# Isaac Duwe — Portfólio

## Rodar localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Deploy no Vercel

1. Push para um repositório GitHub
2. Acesse [vercel.com](https://vercel.com) → "New Project" → importe o repositório
3. Clique em "Deploy"

Pronto. Live em ~2 minutos, sem configuração adicional.

## Customizar

- **Dados pessoais, projetos, skills:** edite `lib/data.ts`
- **Cores e fontes:** edite `tailwind.config.ts` e `app/globals.css`
- **Estilo do cursor:** `components/ui/CustomCursor.tsx`
